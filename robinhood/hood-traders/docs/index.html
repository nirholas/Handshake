02 / EVERY TICK · six stages

A strategy can never
bypass the risk gate.

Each tick runs the same six stages. The strategy only proposes; the agent simulates a real Uniswap v3 eth_call, prices the fill, and runs the risk engine, which fails closed, before anything executes. Every trade and every refusal lands in the journal.

03 / STRATEGIES · edge & failure, stated honestly

Documented, not guaranteed.

Each strategy carries its edge hypothesis and its primary failure mode, exposed at runtime as strategy.meta, the radar and this page read the live values, never a stale copy.

Most new memecoin launches go to zero. Thin Stock Token pools can move against you, and software has bugs. Paper mode simulates fills against live market data and is the default; live mode requires HOOD_TRADERS_LIVE=1 and a funded key, and Stock Token trading additionally requires an explicit non-US-person eligibility affirmation. There is no accidental-live path.
04 / RISK LAYER · enforced, not advisory

Every cap fires
before execution.

These are enforced in code, not in a prompt. Every one applies identically in paper and live mode.

Kill switch.
Three triggers.

Any one halts new orders across the whole fleet immediately. It never force-sells, stopping new risk and unwinding a position are different decisions.

Signal
SIGINT / SIGTERM, Ctrl-C or docker compose stop.
File
Drop a KILL file and the fleet halts on the next tick.
HTTP
POST /api/kill from anywhere with reach to the dashboard.

Paper mode in
five minutes.

No wallet, no key, no config. Paper mode simulates fills against live market data, real Chainlink prices, real Uniswap v3 quotes. Built on the hoodchain SDK. Open the dashboard: fleet equity, per-agent P&L, open positions, and the full decision journal.
