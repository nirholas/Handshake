Three pieces, each usable alone

Ship a whole checkout, or drop in just the part you need. Every module is typed, tree-shakeable, and verified against on-chain USDG.

W

Checkout widget

One <script> and one div. Connect wallet, ensure chain 4663, pay USDG. Under 27 kB gzipped, every visual state designed.

L

Hosted payment links

The request is encoded in the URL fragment, so a link is a full checkout that runs entirely client-side. No server, no database, no fee.

V

Merchant verify

A reorg-safe watcher confirms amounts on-chain (never from the DOM), fires signed webhooks, and records to an idempotent SQLite ledger.

Embed in two lines

Point data-pay-to at your address, set an amount, done. The buyer's wallet signs; funds go straight to you.

<!-- your merchant address + the amount you want to charge -->
<div data-hoodpay
     data-pay-to="0x4022de2D36C334E73C7a108805Cea11C0564f402"
     data-amount="25.00"
     data-memo="Order 1042"></div>
<script src="https://nirholas.github.io/hood-pay/hood-pay.min.js"></script>

Or mount it programmatically

import { mountCheckout } from 'hood-pay/widget'

mountCheckout('#checkout', {
  payTo: '0x4022de2D36C334E73C7a108805Cea11C0564f402',
  amount: '25.00',          // or 'dynamic' for tips / pay-what-you-want
  memo: 'Order 1042',
  onSuccess: (receipt) => console.log('paid', receipt.txHash)
})

Confirm payments on your server

The widget never decides whether a payment is real - your verifier does, by reading the chain. awaitPayment watches for the transfer (or router event), waits out reorgs, and returns a terminal status your shop can trust.

  • paid / underpaid / overpaid / expired - every outcome is explicit.
  • Signed webhooks, Stripe-style, with an idempotent SQLite ledger.
  • Refund helpers for overages and abandoned invoices.

import { networkInfo } from 'hood-pay'
import { awaitPayment, createReader } from 'hood-pay/verify'
import { parseUnits } from 'viem'

const info = networkInfo('mainnet')
const reader = createReader('mainnet')

const result = await awaitPayment(
  {
    token: info.usdg.address,
    payTo: '0x4022de2D36C334E73C7a108805Cea11C0564f402',
    expectedRaw: parseUnits('25.00', info.usdg.decimals)
  },
  { reader, fromBlock: await reader.getBlockNumber() }
)
// result.status === 'paid'
