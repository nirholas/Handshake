02 / THE FOUR BLANK FRAMES

Four frames are
unexposed on purpose.

Examples 09, 10, 11 and 13 depend on sibling packages that haven't shipped yet. Rather than fake them, they ship as blank frames with a note explaining exactly what's missing, so the contact sheet stays honest about the state of the roll.

  • 09 · 10 pay for and sell an API over x402, blocked on hood-api and hood402. USDG has no EIP-2612 permit, so the approve step ships from day one.
  • 11 a scripted MCP client driving chain tools, blocked on hood-mcp.
  • 13 launching a token on testnet, blocked on hood-launcher. The launchpad factory addresses already live in the SDK.
  • Every published frame (01-08, 12, 14) worked first try against the real registry, feeds, and testnet pools, no workarounds needed.
