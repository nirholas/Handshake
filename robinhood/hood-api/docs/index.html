00 / THE ENDPOINT TRANSIT MAP · chain 4663

Every endpoint
is a station.

The Robinhood Chain data API, drawn as a transit map. Each line is a resource; each station an endpoint. Ride a line from the request to its response. The free stations sit before the x402 fare gate, the metered ones beyond it. Tap any station: the map is the docs.

why it exists
01 / THE MISSING LAYER

Nobody prices
these three
side by side.

RWA.xyz is enterprise-paid. CoinGecko has no equity semantics: it can't tell you a Stock Token's premium over its underlying share, or that a uiMultiplier() corporate action just changed what a balance is worth. This API is that missing layer, built on the hoodchain SDK.

premium / discount
The same ticker's Chainlink oracle price and its live DEX mid, with the signed spread between them. A generic price feed shows one number; this shows the gap that is the trade.
multiplier-correct
Portfolios are valued through uiMultiplier(), so a split or corporate action never silently misprices a balance. Robinhood reports what you hold, never what it's worth in shares.
cross-venue
The only place that prices Robinhood Chain, xStocks, and Ondo Global Markets for one ticker in a single call, with the cheapest venue and the spread in bps.
no keys
Free tier is IP-rate-limited and generous. Paid endpoints meter with x402, USDC on Base. No API keys, no accounts, no subscriptions.

03 / THE FIREHOSE · one paid step

Pay once.
Stream free.

The /v1/firehose station is the only metered step: it mints a short-lived signed session token for $0.01. Open the WebSocket with that token and stream free for its ~10-minute life. The paywall stays on the cheap HTTP call while the long-lived connection needs no per-message billing.

One shared upstream subscription per channel fans out to every socket: N paying clients never cost N sequencer connections, and an idle deployment makes zero background calls.

# 1. pay once for a session token (x402, $0.01)curl -H "X-PAYMENT: <header>" \ {BASE}/v1/firehose# 2. connect and subscribe to any channelswss://{host}/v1/ws?token=…&channels=launches,ticks
firehose
Raw sequencer transactions, ~100 to 300ms pre-confirmation.
launches
New NOXA / Odyssey token launches (confirmed log watch).
trades
Odyssey bonding-curve buys and sells.
ticks
Chainlink Stock Token price changes, polled every 15s, emitted only on change.
04 / ARCHITECTURE

Typed routes,
real upstreams,
zero mocks.

Hono with @hono/zod-openapi for typed routes and a generated OpenAPI 3.1 doc, @hono/node-ws for the firehose. Every test hits a real in-process instance against real RPC, Blockscout, DefiLlama, and CoinGecko: no recorded fixtures.

chain reads
hoodchain: Chainlink quotes, Uniswap v3 DEX quotes and pools, the Stock Token registry, launchpad log scans, the sequencer firehose. RPC fails over public → Alchemy when ALCHEMY_KEY is set.
payments
x402-hono gates paid routes against the real facilitator (x402.org for Base Sepolia, CDP for Base mainnet USDC). No X402_PAY_TO? Paid routes return a clean 503 and the free tier still works.
cache
In-process TTL cache with single-flight de-duplication, tuned per resource to each upstream's real cadence: Chainlink feeds vs DefiLlama's daily TVL vs Blockscout holder counts.
05 / GET IT

Free tier runs
with no config.

Every variable has a working default; the free tier needs none of them. Set X402_PAY_TO to a payout address to switch the paid endpoints on. Cloud Run is the preferred target for the always-on firehose; the HTTP routes run fine anywhere.
