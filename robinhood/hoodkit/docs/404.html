    01 / SIX MODULES · one entry point

    Every jack on that board
    is a real export.

    One createHoodClient() from hoodchain flows through all of them. Import only what you patch — hoodkit is side-effect-free and tree-shakes to nothing you don't call.

    02 / THE GUARANTEE · reconnect gap-fill

    A dropped RPC never
    drops an event.

    Every RPC-backed stream sits behind one gap-fill engine. It keeps a persistent block cursor that only advances after a range is decoded and pushed. Lose the connection and the exact same range is re-read next tick — so no confirmed swap, transfer, or launch is ever silently skipped.

    backpressure
    A slow for await consumer never grows memory unboundedly — one source, bounded buffer.
    overflow policy
    latest for price ticks, drop-oldest or block where every value counts.
    coalescing
    100 concurrent getQuote calls collapse into ~1 upstream round-trip.
    zero-RPC reads
    Holder, candle and volume queries answer from the local SQLite index, not the chain.
    runLogCursor · block feedsyncing
    Cursor advancing block by block, each range decoded and pushed before the head moves.
    03 / INSTALL

    Patch it in
    real code.

    The three core modules, wired the same way you just wired the board. hoodchain and viem are peers — hoodkit never bundles them, so your app pins the versions.

    stream
    streamPrices / streamSwaps / streamLaunches / streamPortfolio — a backpressure-safe Stream<T> that is both an emitter and an async iterable.
    cache
    createHoodCache — read-through with request coalescing and per-datatype TTLs. Pluggable CacheStore for Redis or KV.
    batch
    plan / createBatcher — Multicall3 batching with per-read failure isolation; a DataLoader-style batcher coalesces across unrelated code paths.
    indexer
    createIndexer — incremental SQLite sync of Transfer + Swap events; resumes from the last block, answers queries with zero RPC.
    # install — hoodchain + viem are peers npm install hoodkit hoodchain viem # the patch, in code: # stream → cache → indexer → your app import { createHoodClient } from 'hoodchain' import { streamPrices, createHoodCache,   createIndexer } from 'hoodkit' const hood = createHoodClient() const cache = createHoodCache(hood) const idx = await createIndexer({ client: hood,   path: './hood.sqlite', tokens: ['0x…'] }) for await (const t of streamPrices(hood))   render(t.symbol, t.priceUsd)
