01 / WHAT IS MONITORED

Eight surfaces,
one honest verdict.

The probe worker measures each surface every 30 seconds, keeps 90 days in SQLite, and evaluates every sample against a published threshold. A failed probe reports unknown, never green. Gas is informational and can never open an incident.

Full methodology Probe worker source
02 / 90-DAY UPTIME

Ninety days, one bar a day.

Each bar is a day of samples. A day with no data renders gray, never green: the front end detects a young worker and says the window is still filling instead of painting unknown days operational.

operational degraded down no data
03 / INCIDENT TIMELINE

Flap-suppressed. No noise.

Three consecutive bad cycles open an incident; four consecutive good ones close it; unknown never opens or closes anything. Perturb the chain above and entries appear here in real time, exactly as the worker's state machine would record them.

No incidents in the last 90 days. Trip the controls above to see how one would be logged.

05 / RUN IT · never a dead page

Backend optional.
The page still works.

If the worker is unreachable the front end flips to direct probe mode and measures the chain from the visitor's browser with the same thresholds. No secrets, no signing — every call is read-only. Badge and embeddable pill included.
