02 / THE HONESTY STANDARD

Nothing here
is secondhand.

Every tutorial was performed against the real chain before it was written, mainnet reads, testnet writes where a funded wallet existed. The prices are real prices. The transaction hashes are real hashes. A tutorial that wasn't run doesn't ship.

the hoodchain SDK chain docs

What "verified" means in this repo

  • Every command shown was actually run; every output block is a real, unedited capture, or is explicitly labeled otherwise.
  • Where a step couldn't be verified in the build environment, a faucet gated behind a browser challenge, an unverified factory ABI, the tutorial says so plainly, with the specific reason.
  • When testing surfaced a real bug, Tutorial 8's payment-verification example did, the lesson keeps the broken version beside the fix. A tutorial that never shows what wrong looks like isn't teaching.
  • Every code sample sits on one open-source SDK, hoodchain, so the same three lines you read here are the three lines you ship.
