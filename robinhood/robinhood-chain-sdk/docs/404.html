01 / THE MULTIPLIER TRAP

Two mistakes every
generic tracker makes.

Stock Tokens implement ERC-8056: uiMultiplier() is the 1e18-scaled shares-per-token ratio, and it rises with splits and reinvested dividends instead of rebasing balances. Get the math wrong and every corporate action silently corrupts the portfolio. hoodchain gets it right, and its live tests assert the share math against each token's own balanceOfUI().

mistake 01 double-counting value
usd = balance × price × uiMultiplier
The Chainlink feed already returns the multiplier-adjusted token price. Multiplying again double-counts every split.
mistake 02 balances as shares
shares = balance ≠ raw balance
Raw balances are not share counts. A generic tracker reports the wrong share equivalent after any corporate action.
hoodchain both, correctly
value = balance × feedPrice
shares = balance × uiMultiplier ÷ 1e18
Two numbers per position, each derived the one correct way — verified on-chain in the test suite.
