01 / THE RAILS · never guessed

Every rail proven
against a real tx.

Four ways to get a token on chain 4663. Each rail's calldata is reproduced byte-for-byte from a real historical mainnet transaction, re-run as a test on every build. The one rule this whole project follows: never guess calldata.

NOXAmainnet · one call
One launchToken call deploys the ERC-20, creates a Uniswap v3 pool, seeds single-sided liquidity, and permanently locks the LP. Trading starts immediately.proof: reproduces the real ROBINDOG launch tx 0x63da…56d0 byte-for-byte, selector 0x686399cb. ABI recovered from NOXA's own production frontend bundle.
Odyssey · instantmainnet · payable
One payable call to The Odyssey's instant factory: msg.value folds directly into the initial buy and lists to a Uniswap v3 pool immediately.proof: reproduces two real create txs byte-for-byte, selector 0x548eb31b.
Odyssey · bondingmainnet · native-ETH curve
Create on the native-ETH bonding-curve factory (zero value), with an optional separate buy to seed the curve.proof: reproduces two real create txs byte-for-byte, selector 0x56f698a3; buy shape matches a real buy tx, selector 0xcce7ec13.
Directmainnet + testnet · own code
Deploys HoodToken.sol (OpenZeppelin v5 ERC20, fixed supply, no mint, no owner, nothing to renounce), creates and initializes a Uniswap v3 pool, seeds a full-range LP, then burns or time-locks the LP NFT per config.proof: no reverse-engineering, code hood-launcher wrote and compiled, submitted for Blockscout source verification on both mainnet and testnet.

03 / AUTONOMOUS MODE · hard caps

It can watch,
propose, and wait.

The scheduler polls the free three.ws crypto-news digest for real clustered narratives, builds a concept from the strongest un-proposed one, and runs it through preflight. Execution needs an explicit approval or AUTO_APPROVE=1, and nothing broadcasts a real transaction unless LIVE=1 is also set. Approval and liveness are independent gates.

read the docs
$ hood-auto tick # one poll-propose cycle $ hood-auto list # pending proposals $ hood-auto approve <id> $ hood-auto loop --interval-minutes 60
launches / day
MAX_LAUNCHES_PER_DAY (default 3): a rolling 24h window over the launch ledger. Hard, not advisory: throws CapExceededError, no override flag.
seed value
MAX_SEED_USDG (default 50): a live Uniswap v3 WETH→USDG quote converts the seed to a USD estimate before every launch.
kill switch
SIGINT / SIGTERM, a KILL file, or POST /kill: any one stops all further launches for the life of the process. No in-process un-kill.
liveness
LIVE=1 + ACKNOWLEDGE_LAUNCH_RESPONSIBILITY=1 required before any real fund movement. Without them, every entry point runs to preflight and stops.
