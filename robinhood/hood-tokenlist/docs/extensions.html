Extension schema

Every entry carries an extensions object with Robinhood-Chain-specific facts that plain token lists cannot express. All values are verified on-chain at refresh time. Typed definitions ship with the npm package (hood-tokenlist, see src/index.d.ts).

Fields

FieldTypeApplies toMeaning
assetClass string all stock-token, memecoin, stablecoin, or wrapped-native
chainlinkFeed address | null all Chainlink price feed proxy on chain 4663, or null when none exists. Feed answers are already uiMultiplier-adjusted; never re-apply the multiplier to a feed price.
chainlinkFeedDecimals number | null priced tokens Decimals of the feed answer (8 for USD feeds)
supportsUiMultiplier boolean all True when the token implements ERC-8056 uiMultiplier(). True for every Stock Token: raw balance times uiMultiplier (1e18-scaled) equals the true position after splits and stock dividends. Ignoring it misstates positions.
eligibility string stock tokens not-for-us-persons: acquisition is restricted, see eligibility. Display of data is unrestricted.
launchpad string memecoins noxa (instant Uniswap v3 listing) or odyssey (bonding curve, listed after graduation)
uniswapV3Pool address memecoins The token's canonical Uniswap v3 pool (created at launch or graduation, LP locked by the launchpad)
uniswapV3PoolFee number memecoins Pool fee tier in hundredths of a bip (10000 = 1%)
launchBlock number memecoins Block of the NOXA launch or Odyssey graduation event
launchRestrictionsEndBlock number NOXA memecoins Block at which NOXA's launch anti-snipe restrictions expire (NOXA stamps a far-future constant; tradability is verified live by simulation instead, see criteria rule 6)

Reading a live price

// viem, against the public RPC (read-only, no key)
import { createPublicClient, http, parseAbi } from 'viem'
import { robinhood } from 'viem/chains'
import { getToken } from 'hood-tokenlist'

const client = createPublicClient({ chain: robinhood, transport: http() })
const aapl = getToken('0xaF3D76f1834A1d425780943C99Ea8A608f8a93f9')

const [, answer] = await client.readContract({
  address: aapl.extensions.chainlinkFeed,
  abi: parseAbi(['function latestRoundData() view returns (uint80,int256,uint256,uint256,uint80)']),
  functionName: 'latestRoundData',
})
console.log(`AAPL: $${Number(answer) / 1e8}`)

Tags

Tags mirror the extension facts for interfaces that filter by tag: stock, memecoin, stablecoin, wnative, priced (has a live Chainlink feed), noxa, and odyssey. Definitions live in the list's top-level tags map.

Logos

Stock Tokens get deterministic ticker-monogram SVGs (a consistent generated system; company trademarks are never shipped). Memecoins self-host a copy of their own artwork where it is resolvable, with the monogram as fallback. All assets live in this repo under logos/, keyed by checksummed address, and are served from the same stable origin as the list.
