01 / ADD THE NETWORK

One call adds a
chain from scratch.

ensureChain() connects, adds 4663 via EIP-3085 if the wallet has never heard of it, switches, and verifies, with a typed state for every phase and a typed error for every rejection path, including MetaMask's nested -32603/4902 wrapping.

The add-chain params are provably derived from viem: toAddChainParams() computes them at runtime from viem's official robinhood / robinhoodTestnet definitions. Nothing is hand-copied, and the test suite enforces it.

npm source add-to-wallet button
// EIP-6963 discovery + legacy fallback import { discoverWallets, ensureChain } from 'hood-connect' const wallets = await discoverWallets() const { address } = await ensureChain( wallets[0].provider, { network: 'mainnet', // 4663 onState: (s) => log(s.status) } ) // connecting → adding → switching → connected
02 / FUND THE FUNNEL

Bridge in from
anywhere you already are.

The empty wallet every new 4663 user has is the whole problem. checkBootstrap() spots it and hands back concrete funding options; getFundingQuote() returns a ready-to-send bridge transaction, priced live, LI.FI first and Relay behind it. The documented "withdraw from the Robinhood app" path is offered alongside for anyone who prefers the front door.

03 / CONNECT · every state designed

Drop in the button.
Or keep the core.

<HoodConnectButton /> and <FundWallet /> carry the whole journey with a themable skin: no wallet, picker, connecting, adding, switching, wrong chain, connected, empty wallet, error: each visual state is drawn. Already on wagmi v2? hoodWagmiConfig() wires chain 4663 in. The framework-free core needs neither React nor wagmi.

import { HoodConnectButton, FundWallet } from 'hood-connect/react' <HoodConnectButton showBalances onFund={() => openFunding()} /> <FundWallet onFunded={() => refetch()} /> // headless, if you'd rather: // useHoodAccount · useEnsureChain · useWallets
discovery
discoverWallets / watchWallets: EIP-6963 one-shot or streaming, with a legacy window.ethereum fallback for wallets that never adopted it.
typed errors
ConnectionRejectedError, ChainAddRejectedError, ChainSwitchRejectedError and siblings, never a raw provider error, so your UI branches on a name, not a magic number.
balances
checkBootstrap reads live ETH + USDG and, for the empty wallet, returns funding options ready to render. Stock Tokens are shown, never acquired.
theming
Skin the components with --hc-* CSS variables, or take unstyled and paint it yourself. Every state has a class hook.
