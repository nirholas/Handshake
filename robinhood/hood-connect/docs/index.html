Wallet onboarding for Robinhood Chain, in one component.

Chain 4663 ships in no wallet by default, so every dApp rebuilds the same flow: add network, fund via bridge, connect. hood-connect makes it one call: EIP-6963 discovery, EIP-3085 add-network derived from viem's official chain defs, live ETH/USDG balances, and a bridge funding funnel routed through LI.FI with Relay fallback.

60-second quickstart

Framework-free core. React and wagmi variants live in the integration guide.

import { discoverWallets, ensureChain, checkBootstrap } from 'hood-connect'

const [wallet] = await discoverWallets()          // EIP-6963 (+ legacy fallback)
const { address } = await ensureChain(wallet.provider)  // connect + add 4663 + switch

const status = await checkBootstrap(address)      // live ETH + USDG read
if (!status.funded) {
  console.log(status.fundingOptions)              // bridge + Robinhood-app paths
}
