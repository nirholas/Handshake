The funding funnel

Adding chain 4663 gets a user connected; it does not get them gas. The funnel closes that gap: live bridge quotes and one-transaction route execution from any major chain, without leaving the dApp, plus a documented path for money already inside the Robinhood app.

How routing works

  1. Quote via LI.FI (li.quest/v1/quote). LI.FI aggregates bridges and listed Robinhood Chain (id 4663) at build time; its live quotes for 4663 route through Relay's depository. Keyless and CORS-open, so quoting works client-side on GitHub Pages.
  2. Fallback to Relay (api.relay.link/quote) when LI.FI has no route. Relay lists Robinhood Chain with deposits enabled and quotes ETH into 4663 in about 2 seconds of bridge time.
  3. Execute from the user's wallet. The quote contains a ready-to-send transaction for the source chain; the kit switches the wallet there, sends it (plus an ERC-20 approval first when bridging tokens like USDC), and polls the provider's status API until funds land on 4663.
Verified live. Both APIs were probed against chain 4663 during the build (2026-07-15): LI.FI listed the chain and quoted 0.002 ETH Arbitrum to Robinhood Chain (tool relaydepository); Relay listed depositEnabled: true and quoted the same route with a 2s ETA. The test suite re-verifies both on every npm run test:live.

Core API

import { getFundingQuote, getFundingStatus, listFundingChains } from 'hood-connect'

const chains = await listFundingChains()   // source chains, live from LI.FI

const quote = await getFundingQuote({
  fromChainId: 42161,                      // Arbitrum One
  fromAddress: account,
  amount: 10_000_000_000_000_000n,         // 0.01 ETH in wei
})

// quote.toAmountFormatted  -> ETH received on 4663
// quote.etaSeconds         -> bridge duration estimate
// quote.approval           -> ERC-20 approve tx when needed (USDC etc.)
// quote.tx                 -> { chainId, to, data, value } ready to send

const txHash = await wallet.request({
  method: 'eth_sendTransaction',
  params: [{ from: account, to: quote.tx.to, data: quote.tx.data, value: toHex(quote.tx.value) }],
})
await getFundingStatus(quote, txHash)      // 'pending' | 'done' | 'failed'

Or drop in the React component; it renders the whole flow (chain picker, debounced live quotes, execution progress, designed error and success states): 

import { FundWallet } from 'hood-connect/react'

<FundWallet onFunded={() => refetchBalances()} />

From the Robinhood app

Users who already keep crypto in the Robinhood app or Robinhood Wallet can skip bridges entirely; the app withdraws ETH straight onto Robinhood Chain.

  1. Open the Robinhood app (or Robinhood Wallet) and go to the ETH holding.
  2. Choose Send, then pick the Robinhood Chain network. Picking Ethereum mainnet here sends to a different chain; the address is the same, the network choice is what matters.
  3. Paste the connected wallet address (the FundWallet component displays it with a copy control).
  4. Confirm. Funds arrive on chain 4663 in about a minute, and checkBootstrap flips to funded: true.

Stock Token note. Stock Tokens are tokenized debt securities issued by Robinhood Assets (Jersey) Ltd and may not be offered, sold, or delivered to US persons (additional limits apply in Canada, the UK, and Switzerland). The funding funnel moves ETH and stablecoins only; it never acquires Stock Tokens.
