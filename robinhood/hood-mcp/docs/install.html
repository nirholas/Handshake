Install matrix

One line, no key.

The data server runs against the public Robinhood Chain RPC with no account, no API key, and no wallet. Every snippet below is the exact config used to produce the session transcript. Node 20 or newer.

Claude Code

claude mcp add hood-mcp -- npx -y hood-mcp

Then ask it something the chain can answer, for example "what is AAPL trading at on-chain and what is the premium?". Remove it again with claude mcp remove hood-mcp.

Claude Desktop

Add to claude_desktop_config.json and restart the app.

{
  "mcpServers": {
    "hood-mcp": {
      "command": "npx",
      "args": ["-y", "hood-mcp"]
    }
  }
}

Cursor

Add to .cursor/mcp.json in the project, or the global config.

{
  "mcpServers": {
    "hood-mcp": {
      "command": "npx",
      "args": ["-y", "hood-mcp"]
    }
  }
}

Smithery

smithery.yaml ships in the repo root and declares the stdio start command plus the two optional settings below. Smithery installs the read-only data server only; the trading server is deliberately not exposed there. 

startCommand:
  type: stdio
  configSchema:
    type: object
    properties:
      HOOD_MCP_NETWORK: { type: string, enum: [mainnet, testnet], default: mainnet }
      ALCHEMY_KEY:      { type: string }
    required: []

Any stdio MCP client

npx -y hood-mcp

Speak JSON-RPC on stdin/stdout. The transcript shows the exact frames a client sends and receives, starting with initialize.

Streamable HTTP

For browser-based or remote clients, run the same server over HTTP. It serves POST /mcp and GET /health, stateless (a fresh server per request), with CORS open and the Mcp-Session-Id header exposed. 

npx -y hood-mcp --http            # or HOOD_MCP_TRANSPORT=http
curl -s http://localhost:8730/health
{"ok":true,"server":"hood-mcp","version":"0.1.0","network":"mainnet"}

Environment

Nothing here is required for the data server. The trading server's variables are documented on the safety model page.

VariableDefaultWhat it does
HOOD_MCP_NETWORKmainnetTarget network: mainnet (chain 4663) or testnet (chain 46630).
ALCHEMY_KEYunsetRoute RPC through Alchemy instead of the public endpoint. Faster and unthrottled on the heavy portfolio and launch scans.
HOOD_MCP_TRANSPORTstdioSet to http to serve Streamable HTTP instead of stdio.
HOOD_MCP_PORT8730Port for the HTTP transport.

Run from a checkout

git clone https://github.com/nirholas/hood-mcp
cd hood-mcp
npm install
npm run build
node dist/data-server.js            # stdio
npm run docs                        # recapture the session + rebuild this site

Point a client at the local build with an absolute path instead of npx: {"command": "node", "args": ["/abs/path/hood-mcp/dist/data-server.js"]}.
