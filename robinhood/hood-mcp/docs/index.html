That premium is the whole trade: a Stock Token can drift from its oracle, and an agent that can read both sides in one tool call can act on the gap. get_stock_quote returns the oracle price, the DEX price, the spread, and the ERC-8056 uiMultiplier so the underlying share price is never misstated after a split.

Reproduce it. npm install && npm run build && npm run docs re-runs the capture against the chain as it is right now and re-renders this page. The numbers above will differ from yours, because they are real.

← 9 toolsschemas in the reference
ToolDescription the model routes on
get_chain_statsLive Robinhood Chain overview: latest block, gas price, TVL, and network totals (blocks, addresses, transactions, block time). No inputs.
list_stock_tokensThe registry of tokenized-equity Stock Tokens on Robinhood Chain (ticker, name, contract, Chainlink feed). Set pricedOnly to return only tokens with a live feed.
get_stock_quotePrice a Stock Token by ticker: the Chainlink oracle price, the on-chain Uniswap DEX mid price, the premium/discount between them, and the ERC-8056 multiplier (so you also get the underlying share price).
get_portfolioMultiplier-correct Stock Token portfolio for any address: per-position token balance, ERC-8056 share-equivalent, USD value, plus the USDG cash balance. Read-only.
get_coinDetail for any Robinhood Chain token by contract address: price, 24h volume, liquidity, FDV, holder count, and whether it is a registered Stock Token.
list_trending_coinsThe trending pools on Robinhood Chain right now (memecoins and stocks) with price, 24h volume, price change, and liquidity — the pulse of the chain.
get_recent_launchesRecently launched tokens on Robinhood Chain launchpads (NOXA and The Odyssey), newest first, scanned from on-chain logs.
watch_launchesWatch NOXA + The Odyssey live for new token launches, blocking up to waitSeconds (or until limit launches are seen), then returns what appeared. Falls back to the most recent launch if none fire in the window.
search_tokenFind tokens on Robinhood Chain by ticker, name, or contract address — searches the Stock Token registry and the Blockscout index together.

Add it to your client

The data server is zero-config and read-only: no API key, no wallet, no account. The full matrix (Claude Desktop, Cursor, Smithery, raw stdio, Streamable HTTP) is on the install page. 

claude mcp add hood-mcp -- npx -y hood-mcp

Data server free

9 read-only tools: quotes with the oracle/DEX premium, multiplier-correct portfolios, launches, trending coins, chain stats, token search.

Tool reference →

Trading server opt-in

A separate binary that never starts unless you set HOOD_MCP_ENABLE_TRADING=1 and a wallet key. Hard USD spend caps per call and per session, plus a simulate-then-confirm round trip on every mutating tool.
