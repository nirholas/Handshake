01 / WHAT THE NEEDLES MEAN

Two feeds,
one truth,
one spread.

The oracle needle reads the Chainlink price feed, the reference the token is supposed to track. The DEX needle reads the live Uniswap v3 mid on Robinhood Chain, what the market will actually fill. When they diverge, an agent that can see both has an edge one that can't will never notice.

oracle · chainlink
The on-chain price feed round data. This is the "should be" number, the underlying share's value, delivered by the same infrastructure the token issuer references.
dex · uniswap v3
The pool's live mid, read directly on-chain (GeckoTerminal has not indexed chain 4663 yet). This is the "is" number: where a swap clears right now.
premium / discount
(dex − oracle) ÷ oracle. Positive means the token trades rich to its underlying; negative means it's cheap. Thin liquidity, weekend gaps, and corporate actions all open it.
uiMultiplier
A split or corporate action changes what a raw balance is worth. get_portfolio reads the multiplier so a position is valued in real shares, never raw units.

04 / THE TRADING GUARDS

Four gates before
anything is signed.

The trading server moves real value on a real chain: there is no sandbox. So the guards are enforced in code, as thrown errors, not as polite instructions in a prompt.

01 kill switch
The process refuses to start without HOOD_MCP_ENABLE_TRADING=1. Off by default, always.
02 eligibility gate
Buying a Stock Token throws unless HOOD_MCP_ACKNOWLEDGE_ELIGIBILITY=1, so they're barred to US/CA/UK/CH persons. Memecoins are unrestricted.
03 spend caps
Every call is valued in USD and checked against MAX_SPEND_USDG (per-call, default 25) and MAX_SESSION_USDG (per-process, default 100) before signing. Fails closed if it can't be priced.
04 confirm gate
The first execute_swap / transfer_usdg returns a simulation and signs nothing. Only a second call with confirm: true and identical args broadcasts.
Stock Tokens are tokenized debt securities (issuer: Robinhood Assets (Jersey) Ltd) and may not be offered, sold, or delivered to US persons. Additional limits apply in Canada, the UK, and Switzerland. hood-mcp only displays Stock Token data by default; the eligibility gate exists so acquiring one is a deliberate, acknowledged act.
