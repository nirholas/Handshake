01 / ONE IMPORT, SENSIBLE DEFAULTS

No RPC URL.
No ABI. No config.

Public RPC by default. Every read call needs nothing at all: no wallet, no key. Only swap needs one. Every function is async and throws a single HoodError on failure, never a raw viem error. It wraps hoodchain the way axios wraps http.

npm source
import hood from 'hood-js' const { usd } = await hood.price('AAPL') const top = await hood.coins({ limit: 5 }) const q = await hood.quote({ sell: 'USDG', buy: 'WETH', amount: 100 }) // spread the quote straight into swap() const { url } = await hood.swap({ ...q, wallet })
02 / ONE ERROR TYPE, STABLE CODES

Every failure is a
HoodError.

Plain-language message, a stable code you can branch on, and the original error on cause. Never a raw viem stack. A batched prices() never fails wholesale over one bad ticker: unpriced symbols come back null, only a single price() throws.

03 / BROWSER & NODE, SAME IMPORT

Runs from a
script tag.

A plain <script type="module"> against any ESM CDN, no bundler required. For swap() in the browser, pass window.ethereum (or any EIP-1193 provider) as the wallet and hood-js drives it directly. In Node, pass a 0x private key read from an env var.

Stock Token eligibility. Stock Tokens are tokenized debt securities (issuer: Robinhood Assets (Jersey) Ltd) and may not be offered or sold to US persons (also Canada, UK, Switzerland). Buying one throws NEEDS_ELIGIBILITY until you acknowledge eligibility; reading, holding, and selling are never gated. Memecoins are never gated.

04 / GET IT

Install, and
you're trading.

viem is the only peer. Read calls run against the public RPC out of the box. The quickstart below is verbatim what ships in the repo root as quickstart.mjs.

read the docs hoodchain
# Node >= 20, or any modern browser $ npm install hood-js viem # run the shipped quickstart verbatim $ node quickstart.mjs # own code: 4.55 kB gzipped (budget 15) $ npm run build && npm run size
