# LongCat-Video model dependencies, installed under constraints.txt.
#
# Mirrors upstream's requirements.txt + requirements_avatar.txt
# (github.com/meituan-longcat/LongCat-Video) with four deliberate differences:
#
#   * torch / torchvision / torchaudio install separately from the cu124 index,
#     before this file, so the CUDA build is the one pip resolves against.
#   * flash-attn installs separately from a pre-built wheel. Upstream's plain
#     "flash-attn==2.7.4.post1" is an sdist that compiles for ~40 minutes and
#     needs nvcc, which the CUDA *runtime* base image does not ship.
#   * opencv-python is swapped for opencv-python-headless: the GUI build pulls
#     an X11 stack no server needs.
#   * dropped from requirements_avatar.txt: libsndfile1 (a name squat on PyPI;
#     the real dependency is the apt package, installed in the Dockerfile),
#     tritonserverclient (unused), openai (only imported by the optional prompt
#     enhancer, which this worker does not call), nvidia-ml-py, tzdata, cffi and
#     chardet (nothing on the avatar path imports them), and streamlit/pyarrow
#     (the run_streamlit.py demo UI only).
