The /play world economy

Every price, prize and gate

The open world runs a real economy: a purse you can lose, a bank that protects it, a store that prices every trade server-side, a cosmetics boutique that settles on Solana, and a wheel with published odds. Until now you had to walk up to each NPC to learn any of it. This is the whole thing, in one place.

Nothing below is transcribed by hand. The page reads the same tables the authoritative game server prices trades with, so a number here is the number you will be charged.

Enter the world Read the reference doc Tutorial: earn and spend

The catalogs, gates and odds on this page are served by /api/play/economy, which imports them from the game's own modules rather than restating them, so this reference cannot drift from what the server charges. Cash is a game resource and never leaves the world; only boutique unlocks and paid spins touch the chain, and both are verified on-chain before anything is granted. The separate USDC cosmetics rail for the standalone character creator is documented under Fits.
