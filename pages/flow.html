How to read it

Dot size is value handled. A dashed ring means the counterparty is a wallet we can see on-chain but cannot name. Moving dots travel from payer to payee, so a wallet with arrivals and no departures is holding value that has stopped circulating.

What the money bought

Skill payments carry the name of the service they paid for, so the economy is legible down to the individual capability an agent sold.
