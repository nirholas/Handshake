Checkout Companion

Reads the payment page before you pay.

Your account

If you are signed in to three.ws in this browser, it already works. To connect a specific account instead, paste a companion bridge token from three.ws/companion. Rotating that token there disconnects every device at once.

What leaves your browser

  • The visible text of a page that looks like a checkout, with card numbers, bank accounts, emails, phone numbers, security codes and government ids stripped out first, in this browser.
  • The amounts shown on the page and the label beside each one.
  • The site's hostname. Never the full URL, never the query string.

What never leaves, and what is never kept

  • Anything you type. The reader refuses form fields structurally: there is no code path that reads an input, a textarea, a select, or an editable region.
  • Any page that is not a checkout. Those are filtered before a request exists.
  • Nothing about the page is stored on three.ws. The findings are computed and forgotten.
  • Remembered prices are one number per site, kept for an hour, and never leave this browser except as the single amount used to compare against the total.
