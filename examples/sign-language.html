A signing avatar, two ways

Left: an agent whose every reply is signed, from one HTML attribute. Right: the signing engine on its own, compiling whatever you type into a single animation clip.

Words with a sign are signed; everything else is fingerspelled, in the same continuous motion.

1. Signed chat replies

<agent-3d chat sign-language>. Ask it anything: the answer is spoken in the chat panel and signed on the avatar.

2. The engine on its own

No agent, no chat: compileUtterance() turns text into one clip and the viewer plays it. This is the same code path the attribute above uses.

Type anything and press Sign it.

The engine is published as @three-ws/sign-language with zero runtime dependencies, so it also runs in Node or a worker. The live feature is at three.ws/sign-language, the alphabet reference at three.ws/asl-alphabet, and the full documentation at three.ws/docs/sign-language.
