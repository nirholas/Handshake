Windows 11

Live now

  1. Open three.ws in Edge and install it (the install icon in the address bar).
  2. Open the widgets board (Win + W) and choose Add widgets.
  3. Pick Agent glance. It refreshes itself every 15 minutes.

Signed out is handled: the widget shows a sign-in card rather than an error, and it keeps the last card it saw when the machine is offline.
